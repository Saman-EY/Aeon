# نسخهٔ React + Vite سایت AEON

این پروژه با React، TypeScript، Vite و React Router اجرا می‌شود. طراحی فعلی، چهار زبان انگلیسی، ترکی، فارسی و ایتالیایی و ۶۸ آدرس محتوایی حفظ شده‌اند. فارسی راست‌به‌چپ است.

## اجرا

Node.js نسخهٔ 22.19 یا بالاتر، یا نسخهٔ 24 LTS را نصب کنید. داخل پوشهٔ `webapp`:

```sh
npm ci
npm run dev
```

آدرس محلی نمایش‌داده‌شده را باز کنید.

## خروجی انتشار

```sh
npm run build
npm run preview
```

دستور `build` خروجی معمول Vite را در پوشهٔ `dist` می‌سازد. برای خروجی HTML جداگانهٔ صفحات و حفظ اطلاعات سئو و پیش‌نمایش شبکه‌های اجتماعی:

```sh
npm run build:prerender
```

پوشهٔ `dist` موجود در بسته با همین گزینه ساخته شده است. تمام محتوای این پوشه باید منتشر شود. تنظیمات Vercel هم در بسته قرار دارد. برای میزبان دیگر، ابتدا فایل‌های موجود سرو شوند، آدرس بدون پسوند مثل `/en/about` به فایل `/en/about.html` وصل شود و آدرس‌های باقی‌مانده به `index.html` برگردند. جزئیات تنظیم Nginx در راهنمای انگلیسی است. دریافت مستقیم صفحات و تازه‌سازی صفحه به این تنظیم وابسته است. کد وضعیت واقعی 404 نیز باید در میزبان تنظیم شود.

## تنظیمات

از فایل `.env.example` یک کپی با نام `.env.local` بسازید:

```dotenv
VITE_SITE_URL=https://aeon-st.vercel.app
VITE_CONTACT_EMAIL=
VITE_CONTACT_ENDPOINT=
```

پس از تغییر این مقادیر خروجی را دوباره بسازید. این تنظیمات در مرورگر قابل مشاهده‌اند؛ کلید محرمانه در آن‌ها قرار ندهید.

فرم تماس تا زمان تنظیم سرویس واقعی دریافت پیام غیرفعال است. این نسخه شامل پایگاه داده یا سرویس ایمیل نیست. قرارداد اتصال سرویس در README انگلیسی توضیح داده شده است. با تنظیم ایمیل واقعی، لینک تماس مستقیم نیز نمایش داده می‌شود.

## بررسی و نگهداری

```sh
npm run typecheck
npm run lint
npm test
```

متن‌های چهارزبانه در `src/data`، صفحات در `src/pages` و اجزای مشترک در `src/components` قرار دارند. Hono، Wrangler و وابستگی‌های Cloudflare از این نسخه حذف شده‌اند.
